Desafios de JavaScript: Estruturas de Controle e Fluxo
O usuário pode resolver desafios de código focados em estruturas de controle de fluxo e validar suas soluções em tempo real em HTML, CSS e JavaScript.

A página é dividida em seções que abordam os conceitos fundamentais de controle de fluxo em JavaScript:

* **IF / ELSE (if-else):** Implementação de um classificador de faixa etária com base na idade fornecida.
* **SWITCH (switch):** Conversão de valores numéricos nos dias da semana correspondentes.
* **FOR (for):** Desenvolvimento de um laço de repetição para calcular a soma de todos os números inteiros de 1 até um valor determinado N.
* **WHILE (while):** Utilização de uma estrutura de repetição condicional para contar a quantidade de dígitos de um número inteiro.
* **OPERADOR TERNÁRIO (ternario):** Aplicação de uma condição simplificada de linha única para determinar se um número é par ou ímpar.


## Como usar

1. **Seleção do Desafio:** O usuário deve selecionar uma das abas no topo da página para carregar o exercício desejado.
2. **Desenvolvimento do Código:** No editor de texto localizado do lado esquerdo, deve-se preencher a função preenchendo as lacunas indicadas pelos comentários.
3. **Execução de Testes:** Ao clicar no botão "Executar Testes", o script avalia o código inserido comparando os resultados obtidos com os casos de teste predefinidos.
4. **Análise de Resultados:** O painel do lado direito exibe o status de cada teste, indicando se a solução está correta ou se ocorreram erros de execução ou lógica.

5. **Recursos Adicionais:** O botão "Resetar" permite retornar o código ao seu estado inicial.

Caso encontre dificuldades para resolver o problema, no js esta escondida a função "Ver Solução" preenche o editor com o código correto para fins de estudo. 

## Tecnologias Utilizadas
 
* **HTML5:** Estruturação dos elementos da página.
* **CSS3:** Estilização baseada em Layouts Modernos (Grid e Flexbox), além do uso de variáveis customizadas para a definição do tema visual.
* **JavaScript (ES6+):** Manipulação dinâmica da interface, gerenciamento do estado das abas e execução interna dos testes automatizados.
